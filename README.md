# Локальный ИИ для управления рисками кооперационных проектов

Рабочая база знаний магистерской диссертации: «Разработка организационно-экономического механизма внедрения локальной системы искусственного интеллекта для поддержки принятия решений по управлению рисками кооперационных проектов на предприятиях ГК „Ростех“».

Статус: исследовательский проект, редакция 0.1. Требования кафедры и замечания руководителя пока не предоставлены. Это не официальный материал МГИМО или ГК «Ростех» и не описание их внутренних процессов.

## Разделы
- research — исследовательский замысел и методы.
- knowledge — предметная база и связи понятий.
- skills — инструкции SKILL.md для ИИ.
- resources — источники и стратегия поиска.
- thesis — структура текста и ожидаемые результаты глав.
- solution — концепция системы и проверка качества.
- economics — модель затрат и эффектов.
- data — политика данных и синтетический пример.
- templates — шаблоны карточек.
- project — задачи, решения и будущие требования.

Материалы различают подтверждённые сведения, авторские предложения, гипотезы и пробелы. Не публиковать закрытые документы, персональные данные, ключи доступа и реальные данные проектов без разрешения. Публичность репозитория не означает предоставление открытой лицензии; условия лицензирования пока не выбраны.
