# План работы

Даты и сроки пока не заданы.

| Этап | Результат | Критерий завершения |
|---|---|---|
| 1. Согласование рамки | Паспорт и один практический сценарий | Автор и руководитель подтвердили границы |
| 2. Обзор | Карточки источников и аналитическая таблица | Ключевые тезисы имеют основания |
| 3. Механизм | Процесс, роли и контрольные точки | Понятно кто, что и на каком основании делает |
| 4. Демонстрация | Кейс и протокол сравнения | Результат воспроизводим, происхождение данных раскрыто |
| 5. Экономика | Сценарии и чувствительность | Все значения имеют основания или метки синтетики |
| 6. Текст и проверка | Связанные главы и заключение | Выполнены задачи и учтены ограничения |

## Ближайшие задачи
- [ ] Согласовать паспорт и выбрать узкий сценарий.
- [ ] Получить требования кафедры, когда они появятся.
- [ ] Расширить российскую и эмпирическую часть литературы.
- [ ] Прочитать полные тексты стартовых источников.
- [ ] Согласовать набор метрик и альтернативы сравнения.
- [ ] Определить допустимую эмпирическую базу.

## Приём будущих материалов
Сначала проверить допустимость раскрытия → зарегистрировать требование → сопоставить с паспортом и планом → показать конфликты автору → согласовать изменения → обновить затронутые документы. Не публиковать исходный документ автоматически.
