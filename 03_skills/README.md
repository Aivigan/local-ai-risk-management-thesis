# ИИ-скиллы

Это текстовые инструкции, а не исполняемые программы. Автоматическое обнаружение зависит от используемого ИИ-инструмента. Для ручного применения передай ИИ AGENTS.md, затем нужный SKILL.md и задачу с разрешёнными материалами.

| Скилл | Когда применять |
|---|---|
| [research-planner](research-planner/SKILL.md) | Паспорт, задачи, структура исследования |
| [source-reviewer](source-reviewer/SKILL.md) | Проверка и разбор источников |
| [thesis-editor](thesis-editor/SKILL.md) | Подготовка и редактура разделов |
| [risk-analyst](risk-analyst/SKILL.md) | Разбор кейса и риск-карточки |
| [economic-modeler](economic-modeler/SKILL.md) | Затраты, сценарии, чувствительность |
| [academic-reviewer](academic-reviewer/SKILL.md) | Критическая проверка работы |

Общее правило: при отсутствии данных обозначать пробел, а не достраивать факты.
