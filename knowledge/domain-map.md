# Предметная база

Это рабочие определения проекта, требующие уточнения по литературе.

- Кооперационный проект: проект с взаимозависимыми работами нескольких организаций. Анализировать границы, результаты, сроки, владельцев и точки передачи.
- Риск: неопределённое обстоятельство и его возможное влияние на цели. Не смешивать будущий риск, уже наступившую проблему и наблюдаемый сигнал.
- Локальный ИИ: выбранный вариант размещения и эксплуатации внутри согласованного контура. Состав контура и допустимые сетевые соединения нужно определить отдельно.
- Поддержка решений: представление оснований и вариантов действий; окончательное решение остаётся за назначенным ответственным.

## Рабочая типология рисков
| Категория | Пример синтетического сигнала | Возможная проверка |
|---|---|---|
| Сроки | Дата поставки позже зависимого этапа | Сверка календарей |
| Комплектность | В документах нет подтверждения поставки позиции | Проверка источника и статуса |
| Качество | Зафиксировано несоответствие | Проверка акта и решения ответственного |
| Информация | Разные версии срока в двух документах | Установление актуальной версии |
| Координация | У мероприятия не назначен ответственный | Запрос владельцу процесса |

Эти примеры не описывают реальные предприятия.

## Связи понятий
Сигнал → проверка факта → риск-карточка → оценка → варианты реагирования → решение → контроль исполнения.

ИИ может предлагаться для извлечения и сопоставления сведений. Даты и арифметические проверки следует по возможности выполнять детерминированно. Не предполагать, что LLM сама достоверно оценивает вероятность срыва.
