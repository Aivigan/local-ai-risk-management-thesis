# Политика данных

Публично размещать только разрешённые открытые материалы и явно синтетические примеры. Обезличивание само по себе не является разрешением на публикацию. Внутренние требования и документы сначала проверять вне публичного репозитория.

Для набора фиксировать происхождение, права, состав полей, версии, ограничения и ответственное решение о раскрытии. Не хранить персональные сведения, реальные договоры, реквизиты закрытых проектов, токены, пароли и внутренние адреса.

synthetic/risks.csv — вымышленные примеры для обсуждения схемы, не результаты анализа предприятия. Они не содержат вероятностей и не используются как доказательство эффективности.
